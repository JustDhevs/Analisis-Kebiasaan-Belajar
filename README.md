# Analisis Kebiasaan Belajar dan Nilai Ujian

## Deskripsi
Proyek Data Analytics pemula menggunakan Python untuk mengeksplorasi hubungan antara kebiasaan belajar dan nilai ujian.

Dataset yang digunakan merupakan **data sintetis** sebanyak 50 sampel, bukan data mahasiswa sungguhan.

## Tujuan
- Memahami dan memeriksa kualitas dataset.
- Menghitung statistik deskriptif.
- Membandingkan nilai ujian berdasarkan jam belajar.
- Memvisualisasikan data menggunakan Matplotlib.
- Menganalisis korelasi Pearson.
- Menarik kesimpulan dengan mempertimbangkan keterbatasan data.

## Tools
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Fitur Dataset
- `ID`
- `Jam_Belajar`
- `Kehadiran_Persen`
- `Tugas_Selesai`
- `Jam_Tidur`
- `Nilai_Ujian`
- `Lulus`

## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Instal dependensi:
   `pip install pandas matplotlib`
3. Buka `analisis_kebiasaan_belajar.ipynb` di Jupyter Notebook.
4. Jalankan semua cell secara berurutan.

Pastikan file CSV berada di folder yang sama dengan notebook.

## Catatan
Dataset ini dibuat untuk tujuan pembelajaran. Hasil analisis tidak dapat digeneralisasikan ke mahasiswa sungguhan dan korelasi tidak membuktikan sebab-akibat.
